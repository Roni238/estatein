## Предпросморт ---

## Начало работы

```
$ npm install
$ npm run dev
```

Работа сделана в качестве показательной, некоторые подходы могут быть избыточные

Стек - vu3, ts, pinia, swaper, i18n, tailwind, postcss, vite

* Глобальные scss переменные шривтов и цветов, миксины для адоптивности 
* Использованны tailwind классы для стилизации + @apply для создания собственных глобальных классов
* I18n для локализации страницы (в папке locales), по дефолту выбирается язык браузера, язык можно сменить, для локализации подгружаймых данных решил загружать данные заново (для быстрых загрузок)
* Ts для строгой типизации, переиспользованные интерфейсы вынесены в папку types
* Svg иконки загружаются одним запросом спрайт листом
* Pinia стейт загружает и хранит данные
* Swaper использован для создания слайдеров
* Postcss унифицирует css код, создает префиксы и чистит коментарии перед сборкой
* Lazy-loading`и, отложенная загрузка некоторых элементов и страницы
